# Market-Anchored Adaptive Conformal Triage for Football Forecasting

Code and data pipeline for the paper:

> **From Point Forecasts to Risk-Controlled Decisions: Market-Anchored Adaptive
> Conformal Triage for Football Forecasting**

This repository reproduces every number and figure in the paper. All tables and
figures are generated by the scripts below from the raw data; no result in the
paper is hand-written.

## What the paper does

The pipeline converts three-way football forecasting from a point-classification
task into a risk-controlled routing problem:

1. **Market-anchored probability layer.** A learned model is blended with
   de-vigged closing odds through a convex weight selected strictly before the
   target period. Because zero weight is admissible, the learned model is
   *rejected* when it does not improve the external prior.
2. **Adaptive class-conditional conformal sets.** Class-specific (Mondrian)
   thresholds are updated only after every match on a date has been resolved,
   converting prediction-set size into three actions: singleton → automated
   forecast, doubleton → review, full set → abstention.
3. **Module-admission audit.** An existing LLM run is tested conditionally on
   the cases routed to review or abstention; it is retained only if it adds
   paired out-of-sample value.

## Highlights

- 12,459 matches, top-5 European leagues, seasons 2019/20–2025/26.
- Final benchmark is the **complete** 2025/26 season (1,752 matches), not a
  partial season.
- Strictly chronological splits; every feature is pre-match; scalers and
  missing-value statistics are fit on the training window only.
- Five random seeds, exact McNemar tests, and league-by-week block bootstrap
  intervals; no threshold, weight, or hyperparameter tuned on the test period.
- The pipeline is deterministic: consecutive runs of identical code reproduce
  all numeric result fields exactly.

## Repository layout

```
src/
  # data construction
  data_pipeline.py            # leakage-free feature pipeline
  augment_xg.py               # joins Understat xG features (v3 matrix)
  crawl_understat.py          # fetches Understat data (needs network)
  verify_no_leak.py           # manual pre-match cross-checks
  paths.py                    # repo-relative paths + env overrides

  # predictive baselines
  run_baselines.py            # market / XGB / RF / Elo / Poisson
  run_dixon_coles.py          # Dixon-Coles baseline
  run_walkforward.py          # walk-forward across seasons
  run_ablations.py            # feature-group ablations
  run_shap.py                 # permutation importance
  run_by_league.py            # per-league, per-season, leave-one-league-out
  run_multiseed_paired.py     # five-seed ensembles + paired block bootstrap

  # diagnostics
  run_error_analysis.py       # agreement/disagreement, confidence buckets
  run_draw_analysis.py        # draw class metrics and threshold scan
  run_draw_cost_sensitive.py  # cost-sensitive draw training
  run_draw_deep.py            # per-class Brier decomposition
  run_value_betting.py        # EV-threshold selection experiments
  run_risk.py                 # tiered staking / no-bet policies
  run_policy_comparison.py    # coverage-accuracy and coverage-ROI curves
  run_uncertainty_baselines.py# entropy / 1-Sum p^2 baselines

  # conformal triage (the paper's method)
  run_conformal_selective.py     # marginal/Mondrian LAC, APS/RAPS diagnostics
  run_conformal_walkforward.py   # rolling four-season evaluation + adaptive controller
  analyze_conformal_paired.py    # block-bootstrap paired comparisons
  run_llm_conformal_triage.py    # LLM audit inside triage strata
  run_selective_meta.py          # exploratory error-prediction prototype (not in paper)

  # legacy LLM experiments (reused for the subset audit)
  run_llm.py, analyze_llm.py, analyze_llm_compare.py, run_llm_transcription.py
  llm/llm_client.py, llm/prompts.py

  # shared
  risk.py, evaluate.py

  # artifact generation
  make_upgrade_outputs.py     # generates paper/tables/*.tex and paper/figures/*.png
  make_tables.py              # legacy generator for the previous manuscript
  make_figures.py             # legacy figure generator

results/    # experiment outputs (JSON) = the data source for every table
paper/      # LaTeX source (main.tex), tables/, figures/, cover letter, highlights
data/processed/all_matches_featurized.csv   # final feature matrix
```

## Setup

Python 3.13 (3.10+ should work):

```bash
pip install -r requirements.txt
```

All scripts resolve input/output directories through `src/paths.py`, so no path
editing is required. Three environment variables override the defaults, which is
useful for keeping an experimental run separate from the frozen results:

| Variable | Default | Purpose |
|---|---|---|
| `FOOTBALL_DATA_DIR` | `data/raw/` | raw football-data.co.uk CSVs |
| `FOOTBALL_PROCESSED_DIR` | `data/processed/` | processed feature matrices and splits |
| `FOOTBALL_RESULTS_DIR` | `results/` | JSON/CSV experiment outputs |

## Data

1. **Structured match data** (football-data.co.uk format; leagues E0/D1/F1/I1/SP1,
   seasons 2019/20–2025/26) — download into `FOOTBALL_DATA_DIR` (default
   `data/raw/`). Freely available from football-data.co.uk.
2. **xG data** — fetch from Understat:

```bash
python src/crawl_understat.py    # writes data/raw_understat/*.csv
```

If you use the provided `data/processed/all_matches_featurized.csv`, steps 1–2
are only needed to rebuild features from scratch.

python src/data_pipeline.py

python src/run_baselines.py

python src/run_walkforward.py
python src/run_ablations.py

## Determinism

The pipeline is deterministic. Two consecutive runs of the same code reproduce
all 1,433 numeric fields of `conformal_selective_prototype.json` exactly, and
every model-dependent result file in `results/` is newer than the script that
produced it. Re-running after editing a script will legitimately change numbers;
if you compare against the published values, check out the commit that produced
the paper first.

## Legacy material

scripts belong to the previous manuscript (an uncertainty-index staking study).
They are kept for provenance but are not used by the current paper. The
previous manuscript is recoverable from git history.
